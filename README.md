# Yemot World & Space API

אתר מידע בעברית עם חמישה אזורים:
- שיגורי חלל — Launch Library 2
- חיפוש לוויינים — CelesTrak
- תכנון מעברי לוויינים — תשתית ממשק; חיבור מנוע חישוב/API עם מפתח יבוצע בהמשך
- מידע על מדינות — World Bank API
- עובדות על מספרים — Numbers API

## הרצה
זהו אתר סטטי. פותחים את `index.html` בדפדפן או מייבאים את המאגר ל-Vercel. אין צורך בפקודת Build.

## פריסה ב-Vercel
1. נכנסים ל-Vercel.
2. בוחרים Add New → Project.
3. מייבאים את `dji705/yemot-world-space-api`.
4. משאירים Framework Preset על Other, Build Command ריק, Output Directory ברירת מחדל.
5. לוחצים Deploy.

## הערות
האתר מציג נתונים משירותים חיצוניים ישירות בדפדפן. זמינות, מגבלות שימוש ו-CORS כפופים לספקי ה-API. תצוגת מעברי הלוויינים היא כרגע שלד ממשק בלבד — אין להציג אותה כנתון מחושב עד לחיבור שירות מסלולים.


## ממשק ימות המשיח (IVR)

נוסף endpoint בפורמט `read` של ימות:

```
https://yemot-world-space-api1-pox8.vercel.app/api/yemot
```

הגדירו את כתובת ה-API בשלוחת ימות. התפריט:
1. שיגורי חלל קרובים
2. חיפוש לוויין לפי שם
3. מידע על מדינה לפי קוד בן שתי אותיות באנגלית
4. עובדה מעניינת על מספר
5. מידע על מעברי לוויינים (כרגע הודעת זמינות בלבד; חישוב המעברים עדיין לא מחובר)

המערכת משתמשת בשמות קלט נפרדים לכל חיפוש (`SatelliteName`, `CountryCode`, `NumberInput`) כדי לזהות את שלב השיחה בבקשה החוזרת. הנתונים מגיעים משירותים חיצוניים, ולכן זמינותם כפופה לספקים.
